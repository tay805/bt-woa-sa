# How each result of the paper is produced (In the paper sent for publication)

All commands are run from the repository root. The raw results are already in
`results/final/rows/`, so steps 2 to 4 below reproduce every table and figure in a few minutes without rerunning any simulation.

1. `python run_final.py` runs the simulations (experiments E0 to E7, about 10 CPU hours; E6 needs the Intel data, see the main README).
2. `python analyze_final.py` writes `results/final/stats/summary.csv` (mean, standard deviation, 95 % confidence interval of every metric for every method and scenario), `pairwise_wilcoxon_holm.csv` (BT-WOA-SA against every other method: paired Wilcoxon signed-rank test, Holm-corrected p-value, Vargha-Delaney A12) and `friedman.csv`.
3. `python make_tables.py` writes the LaTeX result tables to `results/final/tables/`.
4. `python make_figures.py` writes the figures to `results/final/figures/`.
5. `python run_validation.py` repeats the ns-3 validation (needs ns-3, see `ns3/README.md`).

## Numbers quoted in the text 

Every percentage in the text is the relative difference of two means in
`results/final/stats/summary.csv` (column `rel_diff` in `pairwise_wilcoxon_holm.csv` for comparisons with BT-WOA-SA). The re-clustering interval result (share of energy spent on control packets) comes from scenario `E0_recluster*`, metric `control_energy_share`. Gate accuracy (share of honest and malicious nodes excluded, detection round) comes from the columns `gate_honest_excluded`, `gate_malicious_excluded` and `gate_detect_round` of the raw rows.
Computation time per set-up phase is `runtime_s / setups` of the raw rows.

## Metric names in the result files

| Column | Meaning |
| :- | :- |
| `FND`, `HND`, `LND` | round in which the first node, half of the nodes, the last node died |
| `COV90`, `COV70` | first round in which less than 90 % (70 %) of the field is covered |
| `packets_generated`, `packets_delivered` | readings generated by nodes; readings that reached the BS |
| `PDR` | packets_delivered / packets_generated |
| `energy_per_packet_mJ` | total energy consumed / readings delivered, in mJ |
| `malicious_CH_share_pre_HND` | share of CH roles held by malicious nodes before HND |
| `missed_pre_HND` | share of observable events with no reading delivered, before HND |
| `recon_rmse_pre_HND` | RMS error between true readings and the BS estimate, before HND |
| `energy_std_stable_honest` | standard deviation of honest nodes' energy before FND, divided by E0 |
| `avg_delay_ms` | idealised TDMA delay from round start to arrival at the BS |
| `control_energy_share` | share of the consumed energy spent on set-up (control) packets |
| `gate_honest_excluded`, `gate_malicious_excluded` | share of alive honest / malicious nodes excluded by the trust gate at set-up phases before HND |
| `runtime_s`, `setups` | wall-clock time of the run; number of set-up phases |
